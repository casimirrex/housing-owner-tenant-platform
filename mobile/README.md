# Housing Owner-Tenant Mobile App

Separate Expo + React Native + TypeScript repository for the tenant and discovery mobile experience.

## Included screens

- Home / discovery dashboard
- Search results
- Property detail
- Matches
- Tenant dashboard
- Profile + preferences
- Visits

## Backend integration

Set:

```bash
EXPO_PUBLIC_API_BASE_URL=http://127.0.0.1:8080
```

If you run on a physical phone, replace `127.0.0.1` with your machine LAN IP.

## Run

```bash
npm install
npm run start
```
